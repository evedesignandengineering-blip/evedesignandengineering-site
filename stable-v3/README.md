# EVEDesign & Engineering website

Static, responsive website for EVEDesign & Engineering.

## Files
- index.html — website
- styles.css — styling
- script.js — mailto contact form
- CNAME — custom domain for GitHub Pages

## Free publishing
Use GitHub Pages with the existing domain `evedesignandengineering.com`.

1. Repository → Settings → Pages.
2. Set Source to Deploy from a branch.
3. Choose `main` and `/ (root)`.
4. Save.
5. Add custom domain `evedesignandengineering.com`.
6. Configure the DNS records shown by GitHub at the domain registrar.
7. Enable HTTPS after the certificate is provisioned.

The contact form is backend-free and opens the visitor's email client with an inquiry addressed to evedesignandengineering@gmail.com.
