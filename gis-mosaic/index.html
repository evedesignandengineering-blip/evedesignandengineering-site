GIS Image Mosaic Tool

Combine multiple GIS export ZIPs into one georeferenced GeoTIFF aerial image, ready to attach in CAD. Your files are processed in this browser and are not uploaded to a server.

1. Add your GIS ZIP files

Each ZIP should contain matching .PNG, .PGW and .PRJ files.

⇧
Drop ZIP files here

or choose multiple ZIP files from your computer

What happens next?

One import instead of many.

1
Read the map placement

Uses each PGW world file and PRJ coordinate reference system.

2
Check compatibility

Checks that images use a compatible projection, pixel scale and north-up alignment before merging.

3
Create one GeoTIFF

Reprojects the mosaic into GDA94 / MGA Zone 50 and embeds its coordinates in the GeoTIFF for CAD.

Important: All tiles must use the same coordinate reference system and north-up world files. Output is GDA94 / MGA Zone 50 (EPSG:28350), inferred from the uploaded imagery’s location. The GeoTIFF stores its projected coordinates internally.
▣ Files stay on your computer during processing
